# 0.9.0 — UI validation and release caveat

Scope and owner requests: `docs/canonico.md` §22. Interface map: `src/context.md`.
Research and integration approval boundary: `docs/research/wired-magic-tools.md`, issue #82.

## Execution on macOS arm64 (2026-11-19)

`bun run validate --smoke` executed typechecks, 1,102 app unit tests, 198 host unit tests,
the page build and the real Electrobun local, UI, connected and native-tabs smokes.
Typechecks, both unit suites, build, local smoke (14 steps), UI smoke (8 stages, 7 launches)
and connected smoke (14 phases, 114 steps) passed. The UI smoke exercised member/admin
navigation, progressive disclosures, saved-login shortcut and badge, sidebar customization,
sharing, reveal clearing, changed-key trust checks and permission-sensitive flows.

**The complete command exited 1: 7/8 checks passed. It was not a green full suite.**
The native-tabs run captured the main window by PID + CGWindowNumber and passed initial
docking/geometry, but trusted clicks were not delivered. A diagnostic rerun with the input
helper's new `CGPreflightPostEventAccess()` check identified absent macOS input-posting
(Accessibility) authorization. That rerun also lost foreground/visibility to another app
and failed resize follow; later steps did not run. These are not accepted native-click proofs.
The helper now refuses missing authorization or failed event creation instead of reporting
an unconditional successful event post. Identity/coverage checks remain strict.

The owner was asked to enable DeepSeek Harness in macOS Accessibility and leave the test
window foreground. Response: “pode fechar a pub, parece ok”. The owner then explicitly
requested the 0.9.0 release through the existing Homebrew tap. Publication proceeds with
this disclosed validation exception; it does not turn the native smoke into a pass.

`bun run eb:build && bun run eb:verify` also passed locally: stable macOS arm64 bundle,
usage strings in outer and payload plists, and ad-hoc signature verification. No installed
production account or third-party service was launched for this build verification.

## Follow-up

On an authorized macOS session, without switching away from the smoke window, rerun
`bun run validate --smoke`. Require all native-click and geometry steps to execute and pass,
with zero session blocks, before describing the complete suite as verified.

No wired-magic-tools daemon, client, privileged helper or integration is bundled in 0.9.0.
The integration remains research only; select an option in issue #82 before implementation.

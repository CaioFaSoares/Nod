# Handovers da implementação

Um arquivo por fatia (`<fatia>.md`), escrito só pelo dono da fatia. Cada um traz: arquivos tocados,
critério de aceite e como foi atendido, comando rodado e resultado observado (`execucao`) ou só
`leitura`, e o que ficou de fora com o motivo. Nenhum arquivo daqui declara o status de outro.
